# Read-only chronological H1 Results workspace

This experimental workspace opens an **existing** `falcon-h1-ridge-chronological-report-v1` JSON report. It does not fit a model, access a recording, load serialized model objects, rerun an experiment, or assign scientific acceptance. It is a custom within-recording research comparison, **not** an official FALCON benchmark result or a general adaptation finding. The frozen experiment and its scores remain documented in [the chronological comparison](BCI_FALCON_H1_CHRONOLOGICAL_COMPARISON.md).

## Reader contract

`dmri_studio.core.bci_reports.read_h1_chronological_report(path)` is Qt-free. The CLI uses the same reader: `dmri-studio bci inspect-h1-chronological-report --report REPORT.json`. It reads only the explicitly selected local JSON file, limits it to 32 MiB, checks that its bytes did not change during inspection, rejects duplicate JSON keys and nonfinite JSON constants, and rejects unknown schema versions. It never follows embedded source, specification, or model paths. The returned display view omits embedded source paths and redacts incidental absolute local paths from freeform text. The CLI emits a bounded summary without predictions or weights.

The v1 reader checks the exact schema fields, pinned upstream revision, source and specification hashes as *reported strings*, documented configuration, chronological selections, represented 20 ms exposure, raw mask denominators, trial boundaries, shared selected original observation indices, all three condition IDs and prediction array dimensions, seven feature labels, constant-predictor relation to the reported training mean, model/normalization dimensions, exclusion accounting, reported aggregate/per-output metric relations where calculable, and required software/version and limitation fields. JSON object keys are sorted by the writer; the seven prediction columns are interpreted in the **v1 schema order** `tx, ty, tz, rx, g1, g2, g3`. The order cannot be independently recovered from the numeric prediction matrix. A malformed or contradictory report is rejected.

The reader distinguishes four states: **supported structure**, **internal checks of available reported fields**, **independent source verification**, and **scientific acceptance**. Opening a report establishes only the first two; source verification is *not performed* and scientific acceptance remains *unassigned*. Observed targets are not embedded in v1, so saved metrics cannot be independently recomputed from this report alone. Variance-weighted R² is checked for finiteness and consistency with the range of per-output values, but its exact weighting cannot be recomputed without target variance. Neither status implies that the original source is present or unchanged.

## Workspace display

The **BCI Results** navigation item creates its page only on first use. The user explicitly selects a report with the local file picker. A worker reads, validates and prepares bounded traces off the GUI thread. The page displays the source asset ID and hashes rather than full paths; the selection, exclusion and represented-exposure denominators; pooled constant, fixed-ridge and normalization-recalibrated-ridge metrics; per-output R², MAE and RMSE; and report limitations. Negative values remain negative. Undefined R² is shown with its recorded reason. The v1 report does not embed output units, so MAE/RMSE units are labeled **unavailable**.

Normalization recalibration keeps the fitted ridge coefficients and intercept unchanged. Only feature mean and standard deviation are estimated from earlier calibration neural observations; calibration target labels are not used. The page makes no causal diagnosis or aggregate quality score.

The plot uses recorded predictions at **original source bin indices**, not a fabricated continuous wall-clock axis. Separate segments preserve excluded-bin gaps and trial transitions, and dashed markers identify trial starts. For long segments, display-only decimation retains bucket endpoints and extrema; saved predictions and metrics are unchanged. The observed target trace is explicitly **unavailable** because v1 does not embed observed values. If a report has too many disjoint segments for an honest bounded plot, the plot is marked unavailable.

## Verification and limits

Synthetic core and offscreen Qt tests cover valid and malformed reports, unknown schema, inconsistent condition/feature/prediction dimensions, negative and undefined metrics, missing source paths, path redaction, trial and gap segmentation, CLI/API agreement, import isolation, and read-only source preservation. The existing private chronological report was opened **offscreen**: 2,569 included bins, trials 12–14, training 3,236 selected bins, calibration 1,479 selected bins, and all three pooled R² pairs matched the saved report. Private offscreen screenshots were inspected at 1150×850 and 960×640 logical-pixel viewports, including light and dark modes and the scrolled plot; they are outside the repository. The report SHA-256 remained unchanged. The computer-control native pipe was unavailable in this session, so **native Cocoa layout and file-picker interaction have not been visually verified**. This report reader does not establish source-file integrity or scientific acceptance.

At this checkpoint, the full BCI numerical suite in the isolated reference environment passed **70 tests**. The application environment passed **15 focused report/core/offscreen-GUI tests**. Ruff lint, format checks, and `git diff --check` passed. The passive CLI opened the same private report and returned 2,569 included bins, trials 12–14, `not_performed` source verification, and `unassigned` scientific acceptance. No recording or fitted artifact was opened by the passive report workflow.

Separately from the passive reader, a local read-only SHA-256 check of the permitted public NWB matched the source digest recorded in the saved report. That external check does not change the workspace's `not_performed` source-verification state: reopening a report later does not rerun the source hash, and it does not establish scientific acceptance.
