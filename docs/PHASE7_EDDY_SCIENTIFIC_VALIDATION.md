# Phase 7 — EDDY and denoising scientific validation

**Checkpoint:** 7.0 evidence audit and 7.1 controlled protocol, 24 October 2026. Branch `development/phase7-eddy-validation` from Phase 6 commit `8102df1`. No Phase 7 MRI processing, diagnostic-code change, QC threshold change, or preprocessing-policy change has occurred. This document intentionally contains no participant identifier, MRI array, or private filesystem path. The original restricted records retain exact paths, commands, input hashes, and output hashes; they must not be committed or uploaded.

## Question and scope

Does TractoSphere's current MP-PCA → Gibbs → TOPUP/EDDY route produce trustworthy correction and downstream diffusion measures for its eligible acquisitions? The observed combination of positive-infinite weighted CNR and exact-zero inclusive GP prediction residuals is a **real diagnostic failure in earlier local investigation records**, but the upstream cause, motion correction fidelity, and outlier replacement fidelity remain unresolved. Professor Jesper Andersson's owner-reported 13 October 2026 feedback motivates the comparison; it is a hypothesis and methodological advice, not proof that early MP-PCA caused the failure or that EDDY-first is universally correct.

Checkpoints 7.2–7.6 are **not started in Phase 7**. Prior research controls are described below as historical evidence, not as newly executed Phase 7 experiments. The [scientific backlog](SCIENTIFIC_VALIDATION_BACKLOG.md) retains `SV-EDDY01`–`06` and `SV-QC01` as the acceptance register. The [Phase 6 handoff](PHASE6_IMPLEMENTATION_AND_HANDOFF.md) describes interface verification, not EDDY scientific acceptance; the [Phase 0–5 handoffs](PHASE0_AUDIT_AND_HANDOFF.md) remain historical context.

## 7.0 — Evidence audit

### Original anomaly and processing identity

A restricted local EDDY developer-review bundle, plus the older research application's `multi_shell_validation.md` and `multi_shell_failure_followup.md`, identify the problematic **separately processed b≈1000 acquisition**: one b≈0 volume and 20 weighted directions in a 21-volume, 120×120×68, 2 mm, native LAS DWI. The larger study also has separately acquired b≈2000 and b≈3000 series with different echo times; these must not be treated as one interchangeable multi-shell acquisition. Prior metadata audit recorded AP/PA phase-encoding association, 0.126134 s readout, 6/8 partial Fourier, and 17 slice groups. The historical command used volume-level EDDY; it did not request slice-to-volume motion correction. The detailed acquisition association and any ambiguous metadata remain in restricted records and must be rechecked before a new run.

Historical lineage: original DWI → MRtrix conversion → `dwidenoise` MP-PCA (noise map and residual retained) → `mrdegibbs` → separately estimated TOPUP field and a BET fitting mask → `eddy_cpu`. The historical workflow treated the DWI as magnitude data; source reconstruction/complex-data availability must still be authenticated. The EDDY executable was recorded as **fsl-eddy 2401.2, build hf8d6e30_4, FSL 6.0.7.18, macOS ARM64**, executable SHA-256 `26c0b8e17d660d0926923d7cbaf611b8558b335a3535fe72854d50e9f8231bb0`. Its historical command record requests `--repol --cnr_maps --residuals --niter=5 --flm=quadratic --slm=none --resamp=jac --ol_type=sw --initrand=1 --nthr=4 --verbose`, with explicit `--imain`, `--mask`, `--acqp`, `--index`, `--bvals`, `--bvecs`, `--topup`, `--out`, and `--json` files. The full **exact argv and file hashes** are in the restricted `history/eddy.json`; only path-free options are reproduced here. The baseline used the installed default spherical GP/CV hyperparameter objective. The active repository's `core/correction.py` similarly pins EDDY 2401.2 and retains an explicit execution digest, output and gradient checks, shell mapping, CNR/residual checks, GP log parsing, and `scientific_acceptance: pending`. Its current command is an application contract, not evidence that the earlier research adapter used identical source code or every same option.

Prior restricted records report a successful EDDY process exit and corrected-image/gradient integrity but a failed prediction-QC gate: essentially the entire fixed b≈1000 evaluation mask has **positive-infinite weighted CNR** and **exact-zero inclusive weighted residuals**. A read-only voxel-correspondence record found that every nonfinite CNR voxel examined coincided with exact-zero residuals across weighted volumes. The installed EDDY implementation computes CNR using a residual standard-deviation denominator, so division by zero explains the *numerical symptom*. Extremely low fitted noise relative to signal and near-identity inclusive prediction weights support a GP-fit-collapse interpretation; they do **not** establish why the fit collapses, whether early denoising is causal, or whether corrected/replaced intensities are accurate. A single b≈0 residual/SNR of zero is handled separately from the weighted-shell anomaly. No CNR value is clipped or converted to a favorable score.

The earlier research comparison already includes: the MP-PCA/Gibbs baseline; covariance and hyperparameter-objective variations; **omission of MP-PCA with Gibbs retained**; omission of both MP-PCA and Gibbs; a changed second-level model; an output without `--repol`; an isolated EDDY 2602.0 CPU executable; and a prediction-output repeat. No branch met the original strict scientific acceptance gate. The no-MP-PCA/Gibbs-retained control reduced but did not eliminate invalid CNR, and its mask/TOPUP estimates were not a fully fixed-factor comparison. The no-MP-PCA plus GPP control left some invalid voxels and near-zero residuals; changing two factors relative to baseline prevents attribution to denoising alone. The pristine-raw control changed the b≈0/TOPUP/mask as well and yielded degenerate motion/EC estimates. An EDDY 2602.0 identical-input comparison reproduced the baseline arrays. Omitting `--repol` changed final outlier retention, **not** EDDY's internal replacement during fitting. A limited HCP historical comparison had finite CNR but differed in sampling, pairing, platform, build and processing, so it is not a causal control or a production workaround. Prior local research report conclusions are evidence to audit, not independent Phase 7 replication.

This checkpoint checked original-paper abstracts or accessible original-paper sections alongside official tool documentation. Some PMC full-text browser requests returned an access challenge; a complete full-text read of every cited paper is **not** claimed. The historical research records include additional locally saved primary-source excerpts and installed-source inspections, but those are not substituted for new experimental evidence here.

| Source class | Verified finding and limit for this protocol |

| [Veraart et al., MP-PCA](https://pmc.ncbi.nlm.nih.gov/articles/PMC5159209/) and [MRtrix `dwidenoise`](https://mrtrix.readthedocs.io/en/latest/reference/commands/dwidenoise.html) | MP-PCA exploits a noise eigenspectrum; MRtrix explicitly requires denoising before interpolation/smoothing. This supports treating EDDY→standard `dwidenoise` as **methodologically unsupported until separately validated**. |

The FSL guide defines shell CNR from prediction and residual standard deviations and explains internal outlier handling even without final `--repol`. A zero residual denominator cannot be read as exceptional data quality. Exact installed-version behavior must be checked against its recorded source and output. |
| [Andersson et al., outlier replacement](https://pubmed.ncbi.nlm.nih.gov/27393418/) | The published framework motivates testing prediction-based replacement against a suitable low-motion reference. The abstract/paper does not prove any particular replacement in this acquisition is correct. |

## Controlled study protocol — preregistration draft, no execution approval

### Data and execution gate

1. Scientific owner confirms permitted use of the **exact original acquisition** and the restricted local bundle, locates the authoritative archive for missing output arrays, and identifies a scientifically suitable matched movement/low-motion acquisition. No unrelated dataset is substituted because it has similar b-values. If a compatible common-TE public candidate is considered, verify its metadata and method eligibility independently first.
2. In a private, access-controlled workspace, rehash the actual raw DWI, gradients, metadata, reverse-PE reference, baseline input, fitting/evaluation masks, TOPUP files, executable, and restored diagnostics against historical manifests. Record both missing and changed files. Do not modify the source, original histories or approved runs. Confirm raw magnitude status and any earlier interpolation or scanner filtering; absent facts stay unknown.
3. Freeze exact gradient conventions, volume order, shell assignment, AP/PA/readout/echo-time metadata, mask geometry, TOPUP configuration, EDDY 2401.2 build/hash, CPU platform, thread count and all explicit/default EDDY parameters. Record software manifests and complete commands per branch, never just a pipeline nickname. Separate the **EDDY fitting mask** from the fixed evaluation mask. Keep each branch in a new exclusive output directory with a run manifest and hashes.
4. Estimate before authorization: historical four-thread EDDY attempts were about **21–43 minutes each**, around **1 GiB peak per EDDY child**, with several GiB of concurrent processing and storage. This is a planning range from old runs, not a Phase 7 measurement or resource reservation. Set an explicit branch count, free-space/memory budget, cancellation plan and review checkpoint before new work. No expensive MRI command is authorized by this document alone.

### Experiment sequence and controlled branches

**R0 — restore/reanalyze, then reproduce:** First use authenticated restored baseline arrays to independently recompute the voxel/shell/slice/volume CNR–residual correspondence, preserving NaN/+∞/−∞/zero distinctions. Check the original exact command and build. If arrays cannot be restored or trusted, obtain approval for one exclusive unchanged-command replay before other comparisons. Compare bitwise or toleranced hashes and record sources of any nondeterminism. This is `SV-EDDY01`.

**A — no early denoising:** Original eligible DWI, after confirming its reconstruction and signal representation, with the same scientifically eligible pre-EDDY operations as B other than MP-PCA. Keep Gibbs only if its original-data assumptions are verified, matching the historical no-MP-PCA/Gibbs control. A pristine raw/no-Gibbs sensitivity branch is separate because it changes two factors and previously showed degenerate estimates. No-denoise is a **control**, not an approved new default.

**B — MP-PCA before EDDY:** Current validated preparation contract: `dwidenoise` first, then eligible Gibbs correction, then TOPUP/EDDY. Preserve MP-PCA noise/residual maps and exact parameter/patch settings. Reuse the historical B and A attempts for evidence where hashes, commands, and outputs permit; repeat only for a specific missing control or numerical question. For a fair primary A/B comparison, hold the EDDY executable/options, gradients, reverse-PE source, TOPUP field and evaluation region fixed where scientifically valid. Because changing AP b≈0 may alter TOPUP and BET, analyze both the **natural-pipeline effect** and a separately reviewed **fixed-field/fixed-fitting-mask control**; do not pretend the natural pipelines differ in denoising alone.

**C — EDDY before denoising, conditional:** Begin with a methods review of noise distribution after EDDY interpolation, outlier replacement and resampling, plus any proposed post-correction denoiser's assumptions. Standard MRtrix `dwidenoise` must not simply be run after EDDY. Only if a different defensible method and evaluation are approved should C become an executable branch; otherwise record an accepted methodological limitation. Complex-valued denoising requires genuine complex raw data and remains absent if only magnitude data exist.

**Mask factorial:** Once R0 and primary A/B are interpretable, compare anatomically reviewed baseline/fixed fitting masks and prespecified controlled perturbations, including a clearly poor mask only as a sensitivity bound. Preserve one common output evaluation region; report mask inclusion and exclusion separately. This isolates mask from denoising and does not assume modest mask differences explain the anomaly (`SV-EDDY04`).

**Outlier truth:** Select actual movement-corrupted and low-motion repeat measurements with matched diffusion encoding, TE, gradient orientation, PE geometry and anatomical correspondence. Compare predicted replacements to the low-motion reference after an explicitly validated alignment, with reference variability/registration uncertainty. Record original, replaced and low-motion values for detected and undetected slices. Magnitude of replacement alone is not a validity criterion (`SV-EDDY05`).

### Endpoints and analysis rules

- **Primary numerical endpoints:** shell-specific finite/zero/NaN/+∞/−∞ CNR counts and fractions in both fitting and fixed evaluation masks; inclusive residual exact-zero and near-zero distributions; CNR numerator/denominator maps; GP hyperparameters and noise/signal ratio; target-excluded prediction error where actually saved. Near-zero thresholds must be calibrated to the diagnostic datatype, scanner/noise evidence and controls, stated before analysis. Do not invent a universal threshold or replace undefined ratios with zero.
- **Spatial/processing endpoints:** native slice/voxel/volume maps of invalidity; b-value and direction association; motion translation/rotation, EC coefficients, TOPUP field, outlier locations/counts, residual alignment, interpolations and output-gradient identity. Distinguish failed diagnostics from a successful process exit or a visibly smooth image.
- **Replacement endpoints:** reference-aligned prediction error and uncertainty by corrupted/uncorrupted region; false/missed detection, systematic spatial bias and effects on quantitative measurements. A target-excluded EDDY prediction still shares fitted global parameters and is not independent ground truth.
- **Downstream endpoints:** with the same eligible model and rotated gradients, compare FA, MD, AD and RD maps, model residuals, spatial bias and test–retest variability. FOD/tractography are secondary only when valid matching data and resources exist. Summarize paired differences, confidence intervals or bootstrap intervals where sample size permits, effect sizes, and failure fractions; never select a winner from CNR alone.
- **Analysis safeguards:** predeclare masks, shell bins, low-b criteria and exclusion rules; retain all failed runs, missing diagnostics and nonfinite values; stratify by partial Fourier/reconstruction history and sampling density. Treat one acquisition as a case study, not a population-level estimate. No automatic QC approval follows technical execution.
